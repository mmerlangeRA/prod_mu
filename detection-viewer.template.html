Shortcuts and help

Hover a box, list row or map marker to highlight the same object everywhere; click to select it. Drag the bar above the map to resize it (double-click resets). ◀ ▶, Page Up / Page Down (or ← → outside edit mode) move between the images of the current batch. Click a map marker to select its object (it turns amber); a feature with no sighting in this frame opens the frame where it is seen closest (outside edit mode). Map positions can be corrected without touching the boxes: drag a selected marker (in edit mode, any marker) to place it by hand; a grey ring marks the automatic position, and moving a feature moves all its detections. Shift+click adds or removes a marker from the selection; Shift+drag draws a selection box that adds to it, and with "Select box" on a plain left-drag draws one that replaces it. The selection moves together by mouse or with the arrow keys (0.2 m, Shift: 1 m; ← → change frame only when nothing is selected on the map); click the map or press Esc to clear it. Rear view (R) shows only the 180° behind the car, with the rear in the middle; only the boxes in that half are listed and mapped. Edit mode: drag a box to move it, drag a corner to resize, Delete or D removes the selected box, arrow keys nudge it by 1 px (Shift: 10 px), N draws a new box, Esc cancels. Edits are kept in this browser until saved; saving writes analysis/<batch>-reviewed.json through review_server.py (or downloads it when the server is not running), then positions are recomputed.
