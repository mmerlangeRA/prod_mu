Shortcuts and help

Hover a box, list row or map marker to highlight the same object everywhere; click to select it. Drag the bar above the map to resize it (double-click resets). ◀ ▶, Page Up / Page Down (or ← → outside edit mode) move between the images of the current batch. Edit mode: drag a box to move it, drag a corner to resize, Delete removes the selected box, arrow keys nudge it by 1 px (Shift: 10 px), N draws a new box, Esc cancels. Edits are kept in this browser until saved; saving writes analysis/<batch>-reviewed.json through review_server.py (or downloads it when the server is not running), then positions are recomputed.
